# CPG Synergy Redesign (demo)

Five design variants of a marketing site for a CPG marketing agency, each built as a different funnel style.

**Live:** https://cpg-synergy-redesign.vercel.app

| #   | Variant           | Style                        |
| --- | ----------------- | ---------------------------- |
| 1   | The Authority     | Dark luxury power funnel     |
| 2   | The Trust Builder | Light social-proof funnel    |
| 3   | The Closer        | Bold urgency-driven funnel   |
| 4   | The Storyteller   | Editorial narrative funnel   |
| 5   | The Minimalist    | Clean direct-response funnel |

Copy and the competitor research behind the designs are in `src/data/`.

## Stack

React (Create React App), Framer Motion.

## Run it

```bash
npm install
npm start
npm run build
```
